# Privacy Policy for ReelCoach

*Last updated: November 2026*  
*Developer: Amazing Apps (amazingglobalapps@gmail.com)*

ReelCoach is a browser extension that adds playback controls to Instagram, Facebook and TikTok videos. It is built so that it doesn't need to know anything about you.

## Live Privacy Policy

The official web version of this privacy policy is hosted at:  
👉 **[https://amazingglobalapps.github.io/ReelCoachPrivacyPolicy/](https://amazingglobalapps.github.io/ReelCoachPrivacyPolicy/)**

## Summary

- **Zero Network Requests:** ReelCoach operates 100% locally in your browser.
- **Zero Data Collection:** No analytics, no user tracking, no accounts, and no servers.
- **Minimal Permissions:** Only uses `storage` to persist your playback UI preferences (skip interval, hide delay, mirror toggle).
